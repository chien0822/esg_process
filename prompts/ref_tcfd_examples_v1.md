# TCFD 氣候相關風險與機會例句

出處：TCFD 2017 Final Report（Recommendations of the Task Force on Climate-related Financial Disclosures）中譯本，Table 1「氣候相關風險及財務影響實例」、Table 2「氣候相關機會及財務影響實例」。依使用者提供的截圖轉錄，只錄「氣候相關風險／機會」欄的例句（「潛在財務影響」欄未錄）。
括號內為本系統子類別封閉清單的名稱（SPEC 7.4），與中譯本用詞不同時以括號內為準。

## Table 1 氣候相關風險

### 轉型風險

**政策和法規**（政策與法規）
- 提高溫室氣體排放定價
- 強化排放量報導義務
- 現有產品和服務的要求及監管
- 面臨訴訟風險

**技術**（技術）
- 以低碳商品替代現有產品和服務
- 對新技術的投資失敗
- 低碳技術轉型的成本

**市場**（市場）
- 客戶行為變化
- 市場訊息不確定
- 原物料成本上漲

**名譽**（聲譽）
- 消費者偏好轉變
- 產業污名化
- 利害關係人的關注與負面回饋日益增加

### 實體風險

**立即性**（急性）
- 颱風、洪水等極端天氣事件嚴重程度提高

**長期性**（慢性）
- 降雨（水）模式變化和氣候模式的極端變化
- 平均氣溫上升
- 海平面上升

## Table 2 氣候相關機會

**資源效率**（資源效率）
- 採用更高效率的運輸方式
- 使用更高效率的生產和配銷流程
- 回收再利用
- 轉用更高效率的建築物
- 減少用水量和耗水量

**能源來源**（能源來源）
- 使用低碳能源
- 採用獎勵性政策
- 使用新技術
- 參與碳交易市場
- 轉變至非集中式能源

**產品和服務**（產品與服務）
- 開發和／或增加低碳商品和服務
- 開發氣候調適和保險風險解決方案
- 開發新產品和服務的研發與創新
- 業務活動多元化
- 消費者偏好轉變

**市場**（市場）
- 進入新市場
- 善用公共部門獎勵辦法
- 獲得需要投保的新資產和地區

**韌性**（韌性）
- 參與可再生能源項目並採用節能措施
- 能源替代／多元化
